# 2026-11-18 Fish art: the owner approves each piece before the next

> For this round ok. But for future i need to approve one step for it to move onto the next: so if we start with 3d model, then show it to me before designing the icon and let me approve it, same if starting with the icon

- Each piece of a creature's art (3D model, item icon, bucket, spawn egg) is shown to the owner and approved before the next piece is started, **whichever piece comes first**. If the model comes first, the icon waits for the owner's OK on the model.
- It tightens [[2026-11-18 Fish art - one fish in series, fish in parallel]], which put the icon first.
- "For this round ok": the boll's work so far stands (the mob built with placeholder art while its icon is drawn).
