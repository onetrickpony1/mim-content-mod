# Art rounds capped at 3; blind readers on Sonnet

> Lets do 1, and 3 using 3 sonnet helpers instead rather than open specifically for blind reads only. If they never guess we'll switch back

The owner asked why the art work uses so many tokens. They chose two of the savings offered:

1. **Show the owner sooner.** At most 3 critic rounds per piece (it was 8 for the night job), then the best version is installed and goes to the owner. The owner turned down about 1 in 4 pieces the critic had passed, so extra critic rounds bought little.
2. **Blind readers run on Sonnet.** Still 3 fresh readers per blind read, but on the smaller Sonnet model instead of Opus. Only the blind readers change: makers and critics stay as they are.

**Way back:** if the Sonnet readers never name the fish, blind reads go back to the bigger model. Changes [[Art pipeline]].
