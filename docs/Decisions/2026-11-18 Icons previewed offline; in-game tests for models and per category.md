# 2026-11-18 Icons previewed offline; in-game tests for models and per category

> (asked whether flat icons could be checked with an offline hotbar preview instead of a Minecraft run each time) yes, but things which still would benefit from the in-game test like 3d models definitely need the in-game test. and when we're done with a category there must be one in game test for all icons to ensure they actually do work

- **Flat icons** (item icons, buckets, spawn eggs): judged from an offline preview that pastes them into a copy of the real hotbar at the game's GUI scale, beside the vanilla items. No Minecraft run for each version.
- **Anything that benefits from the game** (3D models, entities, blocks, animation, anything lit or in water): still gets an in-game test every time.
- **When a category is finished** (e.g. all tier A fish), **one in-game test covers all its icons**, to prove they load and work.
