# 2026-11-17 Qassatat b; thicker garlic dip; dips get their own container

> b for both qassatat, the garlic deep needs to seem thicker, possibly by being more greyish too rather than so white, also we need to rethink the containers of the dips, as with so many it will be confusing which are dips and which are soups (they share a bowl) so we need something different send a new maker to think this up

- **Qassatat:** candidate b for both, `qassata_irkotta` (b) and `qassata_pizelli` (pea b).
- **Garlic dip** (`dip_tewm`): must look thicker, perhaps greyer rather than so white.
- **Dips need their own container,** different from the terracotta bowl the soups use, so dips and soups can't be confused. A new maker designs it for all the dips: bigilla (changing its accepted bowl), dip tal-ġbejna, dip tat-tonn and dip tat-tewm.
