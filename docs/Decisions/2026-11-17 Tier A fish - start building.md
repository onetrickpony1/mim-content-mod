# 2026-11-17 Tier A fish: start building

> what maltese fish are we adding? or fish common to and found in maltese waters?

> begin building all the tier a fish. they should have an inventory item, a spawn egg, and drop themselves as the item. Seahorses should drop nothing. all the fish should also have a bucket item, where they sit alive in a bucket of water as mc fish currently do.

The tier A fish from [[Content mod list]] section 6: lampuka (dolphinfish), tonn (tuna), sardina (sardine), ċerna (grouper), awrata (sea bream), murina (moray eel) and żiemel tal-baħar (seahorse). Each gets:
- a live swimming mob;
- an inventory item, which the fish drops when killed (**the seahorse drops nothing**);
- a spawn egg;
- a bucket item with the fish alive in water, like vanilla's bucket of cod.
