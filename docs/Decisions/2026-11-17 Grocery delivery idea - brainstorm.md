# 2026-11-17 Grocery delivery idea: brainstorm

> for the ingredients which traders would bring or foreign ingredients generally, id like to set up something as a sort of joke. a lot of people get their groceries delivered from welbees, so building some sort of way to "order" groceries to your door would be super funny. send an agent to come up with possible ideas. some grounded, some wild, some realistic, some less so, etc. gameplay is a key aspect to keep in mind here. we're building a malta minecraft mod, but players need a reason to play it beyond "oh look maltese thing in game"

- **Ideas only:** a brainstorm of ways to "order" imported and foreign ingredients to your door, as a joke on Maltese grocery delivery (Welbee's), from grounded to wild. Nothing is built.
- **Gameplay comes first:** each idea should give players a reason to play, not just show a Maltese thing.
- It may change how imports arrive (today: the wandering trader and shipwreck chests, [[2026-11-15 Content mod – answers 1-6]]).
- † Using the real Welbee's name in a public release would need the same care as Kinnie (ask first, or a parody name).
